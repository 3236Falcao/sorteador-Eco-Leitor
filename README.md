# Sorteador EcoLeitor

Sorteador estratégico de amostra para acompanhamento longitudinal de leitura e escrita.

## Objetivo
Selecionar até 2 alunos por nível em cada turma para coleta de evidências do EcoLeitor, sem transformar a coleta em ranking ou nota.

## Regras atuais
- seleção separada por Turma + Nível;
- até 2 alunos por grupo;
- a seleção é uma amostra planejada;
- a evidência só existe quando o professor realiza o registro;
- os dados da lista de alunos são locais e não fazem parte do repositório público.

## Estrutura
- `app/` aplicação HTML;
- `launcher/` arquivos para execução/atalho Linux;
- `scripts/` scripts auxiliares.

## Status
v0.1 — protótipo funcional para uso pedagógico inicial.
